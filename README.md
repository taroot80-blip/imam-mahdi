# المستور

موسوعة تفاعلية عن الإمام المهدي عليه السلام، بإشراف مجموعة بقية الله.

موقع ثابت يعمل دون إنترنت. لا يحتاج بناءً: افتح `index.html`.

اختبار حساب العمر: `node tests/age.test.js`

## البحوث والمقارنات
قسم بياني يقارن حضور القضية وثبوتها بين المصادر (`js/lab.js` المحرك، `js/charts.js` الرسوم، `js/lab-ui.js` الصفحة، `js/corpus.js` المتون).
- نصوص التطبيق تعمل دون إنترنت. والمتون الكاملة (الكتب الأربعة المتاحة، وكتب الغيبة، وغيرها) في مجلد `corpus/`، تُحمَّل من الشبكة عند اختيارها ثم تُحفظ في الجهاز، ولا تدخل في نسخة أندرويد.
- مصدر المتون: ثقلين thaqalayn.net عبر مستودع ThaqalaynAPI (مجلد V2/ThaqalaynData). إعادة البناء: `python3 tools/build_corpus.py <مسار ThaqalaynData>`
- قيد الفهرسة: بحار الأنوار، والاستبصار، والتهذيب ٥–١٠.
- اختبار المحرك: `node tests/lab.test.js`
